# Personal_Agent
This is real estate agent which can help you to get the apartment based on the matches

This folder has three files, 
1) Jupyter file ( it has a code)
2) Read_me  ( to understand, how to run the code)
3) csv file ( It is synthetic data generated by LLM model)

Jupyter files has almost all libraries, if some of the library is not found then one can install this using below;
pip install library
